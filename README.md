## Featured Projects

**[DocuMind](https://github.com/anshidarinshii/documind)**
End-to-end document Q&A pipeline: extracts and chunks text from PDFs, generates vector embeddings,
stores/retrieves them via similarity search in MongoDB, and logs ingestion/query metadata to a
SQLite relational store. FastAPI backend, React frontend, containerized with Docker and deployable
to Kubernetes, with automated tests.

**[Bill Extraction & Model Evaluation](https://github.com/anshidarinshii/bill-extraction-eval)**
A pipeline that extracts structured data from photos of handwritten Indian bills using multiple
vision-language models, scores each model's accuracy against manually verified ground truth, and
pushes the results into Zoho Books via API.

**[Prompt Flow](https://github.com/anshidarinshii/promptflow)**
A modular prompt-optimisation framework for LLMs — task detection, prompt augmentation, and
semantic ranking-based pruning across a React frontend and Django/Python backend. Built with a
4-person team.

**[Linksy](https://github.com/anshidarinshii/Linksy)**
A community resource-sharing platform (blood bank, food pantry, book exchange), built with a
5-person team.
